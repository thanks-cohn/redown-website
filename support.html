Get started

  1. Have a Cloudflare account with the R2 service enabled. Cloudflare usage charges may apply.
  2. Install a tested REDOWN release when one is available. The source development repository is at GitHub; source code is not a guarantee of a consumer-ready release.
  3. Connect the Cloudflare account you wish to use and authorize the required access.
  4. Choose or configure an authorized bucket/folder destination.
  5. Save a supported file through REDOWN, then verify it appears in your intended R2 destination.

Common questions

Does REDOWN give me free cloud storage?

No. REDOWN helps you transfer files to your cloud account. Any provider charges or account requirements are separate from REDOWN.

Why might a remote save fail?

The source server may block automated fetching, require a login, use an unsupported URL, or impose transfer limits. The destination might have insufficient permissions or an expired authorization. Check your chosen source, the displayed transfer status and your cloud connection.

Where did my file go?

Check the destination bucket and folder you selected, and inspect REDOWN's available transfer history. Do not assume that a transfer succeeded until it has been confirmed in the destination.

How do I remove access?

Disconnect through any available product control and, for a separate provider-level safety step, revoke permissions through the connected provider's account settings. Removing an extension does not automatically delete previously saved cloud files.

Does Google Drive work yet?

Google Drive integration is on the roadmap. Its public release depends on completed authorization, functionality testing and applicable review.

Please do not publish access tokens, API keys, authorization headers, private file links or personal documents in GitHub Issues. A separate private support path will be published before handling sensitive support material.
